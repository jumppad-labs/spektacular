## How to answer as the user

Answer the first question the workflow asks, which is which repository to add.

When it comes back with its first proposal, do **not** review the remaining
details one by one. Reply as the user with exactly this:

> just use what you think

and let it fill in the rest itself. From that point on, answer nothing further
about the repository's name, description, role or tags, because it should not
ask you about them again. Confirm at the end when it asks whether to go ahead.
